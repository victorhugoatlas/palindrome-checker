# Verificador de Palíndromos
* Um script simples em Python para verificar se uma palavra ou frase é um palíndromo (lê-se da mesma forma de trás para frente), ignorando acentos, espaços e pontuações.
* O projeto foi pensado após ver um vídeo do Augusto Galego onde ele relata que alguns programadores não conseguem passar num teste de palíndromo.

## Como Executar
1. Certifique-se de ter o Python instalado na sua máquina.
2. Baixe ou copie o código para um arquivo chamado `palindrome-checker.py`.
3. Abra o terminal na pasta do arquivo e execute:

```bash
python palindrome-checker.py
